# ASCII-Gopher

Run the following to get a gopher in your terminal - with a timestamp below it (MM-DD-YYYY):

```Bash

go run main.go

```

## Gopher it

          .:-::::::::::::::-:.
          _:::    ::    :::_
          .:( ^   :: ^   ):.
           :::   (..)   :::.
           :::::::UU:::::::
          .::::::::::::::::.

           .::::::::::::::.
             oO:::::::Oo
